IMPORTANT:
1. Keep the folder structure exactly as provided.
2. In Netlify Environment variables, set TELEGRAM_BOT_TOKEN (mark secret) and TELEGRAM_CHAT_ID.
3. The Telegram bot must have been started by the receiving account.
4. Deploy the whole project through a Git-connected Netlify site. Do not upload only index.html.
5. Never put the Telegram bot token in index.html or send it in chat.
